# نزيه — المساعد الافتراضي لليوم العالمي لمكافحة الفساد (9 ديسمبر)
### جامعة حائل × هيئة الرقابة ومكافحة الفساد (نزاهة)

هذا المشروع يدمج المشروعين السابقين في موقع واحد:
- من **avatar-kiosk**: صورة الشخصية في المكتب، وتحريك الفم مع الصوت، ورمش العين، وحركة التنفس.
- من **nazaha-kiosk**: نص النظام الذي يعتمد عليه الذكاء الاصطناعي، الإجابات المحلية عند انقطاع الاتصال، أقسام الأنظمة والمسابقة وبلّغ، التوقف التلقائي للتسجيل عند الصمت، والرجوع للشاشة الرئيسية عند الخمول.
- التصميم: الشاشة الطولية الذهبية الداكنة حسب صورة التصميم، مع شريط أقسام أسفل الشاشة.

## محتويات المشروع
| الملف | الوظيفة |
|---|---|
| `server.js` | الخادم الذي يربط الموقع بـ OpenAI، والمفتاح يبقى فيه مخفياً |
| `data/nazaha-law.txt` | نص النظام الذي يعتمد عليه الذكاء الاصطناعي |
| `public/index.html` | الصفحة (اسأل نزيه، الأنظمة، المسابقة، بلّغ) |
| `public/css/style.css` | التصميم، بمقاسات نسبية تناسب أي شاشة طولية |
| `public/js/app.js` | الشخصية والمايك والصوت والمحادثة. **الإعدادات في أعلى الملف** |
| `public/js/law-data.js` | نص النظام مقسماً إلى مواد لقسم الأنظمة |
| `public/js/quiz-data.js` | 12 سؤالاً للمسابقة |
| `public/assets/avatar.png` | صورة الشخصية (1402×1122) |

## التشغيل
1. تحتاج Node.js إصدار 18 أو أحدث، ولا يحتاج المشروع `npm install`.
2. انسخ `.env.example` باسم `.env` وضع فيه مفتاح OpenAI API (من platform.openai.com، واشتراك ChatGPT Plus لا يكفي):
   ```
   OPENAI_API_KEY=sk-...
   ```
3. شغّل:
   ```
   node server.js
   ```
4. افتح http://localhost:3000

بدون المفتاح يشتغل الموقع بالإجابات المحلية الجاهزة وصوت المتصفح (إن وُجد صوت عربي في الجهاز).

### روابط مفيدة
- `/?kiosk=1` يخفي خانة الكتابة (للشاشة التفاعلية).
- `/?test=1` يحرك الفم بدون صوت، لتجربة الإحداثيات بعد تغيير الصورة.

## على الشاشة التفاعلية
```
chrome --kiosk --autoplay-policy=no-user-gesture-required https://رابط-موقعك/?kiosk=1
```
- المايك لا يعمل إلا على HTTPS أو localhost. اسمح للمتصفح بالمايك أول مرة.
- الاستضافة لازم تشغّل Node.js (مثل Render أو Railway أو VPS)، وأضف `OPENAI_API_KEY` في متغيرات البيئة.
- الموقع يرجع للشاشة الرئيسية ويمسح المحادثة بعد دقيقتين بدون لمس (`idleResetSeconds` في `app.js`).

## زر الإعدادات
مستوى الصوت، تشغيل أو إيقاف نطق الإجابات، إظهار أو إخفاء خانة الكتابة، محادثة جديدة، وملء الشاشة. الإعدادات تُحفظ في متصفح الشاشة نفسها.

## التعديل
- **اسم الشخصية وأسلوبها:** `SYSTEM_PROMPT` في `server.js` (الاسم الحالي «نزيه»)، ونص الترحيب `greeting` في `app.js`.
- **الأسئلة السريعة:** أزرار `chip` في `index.html`، وإجاباتها المحلية في `localAnswer` داخل `app.js`.
- **تغيير الصورة:** استبدل `public/assets/avatar.png` بصورة بنفس المقاس، ثم عدّل إحداثيات الفم والعينين في `FACE` أعلى `app.js`. لو تغيّر المقاس عدّل كذلك `width` و `height` لعنصر `canvas` في `index.html`.
- **الصوت والنماذج:** `TTS_VOICE` و `OPENAI_MODEL` وغيرها في `.env`.
- **أسئلة المسابقة:** `public/js/quiz-data.js`.

## ملاحظات مهمة
- راجع الأنظمة والأسئلة قبل العرض. نص نظام الهيئة منقول من الملف المعتمد، أما الأنظمة الأخرى فمكتوبة كملخصات.
- إجابة «معلومات عن جامعة حائل» المحلية عامة جداً (سنة التأسيس من شعار الجامعة). راجعها وأضف ما تريده الجامعة.
- استخدام شعار نزاهة وشعار الجامعة يحتاج تنسيقاً أو موافقة حسب أنظمة الجامعة.
- ضع حداً للصرف في حساب OpenAI قبل الفعالية.
- الخط (IBM Plex Sans Arabic) يُحمّل من Google Fonts، فإذا كانت الشاشة بدون إنترنت يظهر خط النظام.
